## Package boundary

Both hooks share lifecycle, Standard Schema validation, and React 18/19 support, including
`'use client'`. This package adds MCP responses, prompts, resources, and client hooks.
Agent failures become MCP error responses; local failures and cancellation reject.

Execution state is opt-in. Attach an `executionState()` plugin and subscribe with
[`useToolExecutionState()`](/packages/usewebmcp/reference#hooks) where results are displayed.

## Performance

The tool hook measured **3.96 kB gzip**, one mount registration, and zero owner re-renders per
call without an execution-state subscription. React is excluded. See the
[Google/MCP Cat comparison](/packages/usewebmcp/overview#performance) and
[recorded measurements](https://github.com/WebMCP-org/npm-packages/blob/052f451e9353ea112093973b7e14a16f7715e7c7/benchmarks/react-hooks/PRODUCTION.md).

## Runtime requirements

| Surface                       | Runtime                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------- |
| Tool and context hooks        | Native WebMCP, an initialized polyfill, or the MCP-B runtime                    |
| Prompt and resource hooks     | [`@mcp-b/global`](/packages/global/overview) or a configured `BrowserMcpServer` |
| MCP client provider and hooks | A supplied MCP client and transport; no browser registry required               |

MCP `outputSchema` discovery and validation require the MCP-B runtime.
