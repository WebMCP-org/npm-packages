## Package boundary

Both hooks preserve `'use client'` and accept React 18 or 19; browser tests run on React 19. This package adds Standard Schema
conversion and validation, MCP responses, prompts, resources, and client hooks on top of the core
registration lifecycle.
Agent failures become MCP error responses; local failures and cancellation reject.

## Runtime requirements

| Surface                       | Runtime                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------- |
| Tool and context hooks        | Native WebMCP, an initialized polyfill, or the MCP-B runtime                    |
| Prompt and resource hooks     | [`@mcp-b/global`](/packages/global/overview) or a configured `BrowserMcpServer` |
| MCP client provider and hooks | A supplied MCP client and transport; no browser registry required               |

MCP `outputSchema` discovery and validation require the MCP-B runtime.
