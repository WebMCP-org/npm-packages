## Package boundary

The hook uses Community Group [types](https://github.com/webmachinelearning/webmcp-types)
and accepts upstream JSON Schema metadata without runtime validation. Supply native WebMCP, the
[polyfill](/packages/webmcp-polyfill/overview), or [MCP-B runtime](/packages/global/overview).
React 18/19 and `'use client'` are supported. The hook rejects Standard Schema validators such as
Zod. For Standard Schema validation, MCP output metadata, prompts, resources, or formatted agent
responses, use [`@mcp-b/react-webmcp`](/packages/react-webmcp/reference).
