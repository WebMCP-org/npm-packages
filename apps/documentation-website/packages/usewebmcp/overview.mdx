The next agent call observes the updated counter after each click. The hook registers after commit,
keeps the latest committed callback, and removes the registration on unmount.

## Package boundary

The hook uses the Community Group's [`webmcp-types`](https://github.com/webmachinelearning/webmcp-types).
It supplies React lifecycle, execution state, cancellation, and input inference. A supplied Standard
Schema validator runs before local and agent calls, including async validation and transforms.
The package does not install a validation engine, polyfill, or MCP SDK.

`document.modelContext` comes from native support, an initialized
[`@mcp-b/webmcp-polyfill`](/packages/webmcp-polyfill/overview), or
[`@mcp-b/global`](/packages/global/overview). React 18 and 19 are supported, and the published
entry point preserves `'use client'`.

## Choose a hook

| Requirement                                                      | Package                                                  |
| ---------------------------------------------------------------- | -------------------------------------------------------- |
| Browser tools with raw results, state, and Standard Schema input | `usewebmcp`                                              |
| MCP `outputSchema`, annotations, or result formatting            | [`@mcp-b/react-webmcp`](/packages/react-webmcp/overview) |
| Context, prompt, resource, or MCP client hooks                   | [`@mcp-b/react-webmcp`](/packages/react-webmcp/overview) |

Standard Schema support is shared by both packages. The
[boundary explanation](/explanation/strict-core-vs-mcp-b-extensions#why-standard-schema-support-lives-in-the-adapters)
describes why it belongs in the callback adapter. The
[framework guide](/how-to/frameworks) covers runtime setup, and the
[reference](/packages/usewebmcp/reference) covers configuration, state, and migration.
